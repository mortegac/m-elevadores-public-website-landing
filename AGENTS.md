# Preferencias del repositorio

- Realizar los trabajos de este repositorio en la rama `main`, salvo que el usuario indique otra cosa para una tarea concreta.
- Pasar cambios a producción únicamente cuando el usuario lo autorice explícitamente para la entrega actual. Una autorización anterior no se extiende a cambios posteriores. Sin esa autorización, no ejecutar despliegues ni hacer un push que los active automáticamente.
